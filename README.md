# Élite Estates — site immobilier de luxe

Projet universitaire fictif d'agence immobilière internationale spécialisée dans les biens haut de gamme.

## Ouvrir le site

1. Décompresser le dossier.
2. Ouvrir `index.html` dans un navigateur.
3. Une connexion internet est recommandée pour charger les polices et les photographies distantes utilisées dans la démonstration.

## Fonctionnalités

- Navigation responsive ordinateur / tablette / téléphone.
- Catalogue de propriétés stocké dans une structure de données JavaScript.
- Recherche par mot-clé.
- Filtres par pays, ville, type, prix, surface et chambres.
- Fiches détaillées des biens dans une fenêtre modale.
- Formulaire de contact avec confirmation côté interface.
- Identité graphique noir / blanc / argenté.

## Remarque sur la base de données

La version fournie est une démonstration front-end autonome : les propriétés sont stockées dans `script.js`. Pour une version avec véritable BDD, le tableau `properties` peut être remplacé par une API PHP/MySQL ou SQLite.

## Images

Les photographies utilisées dans cette maquette proviennent de liens distants afin de garder le dossier léger. La mention « Images générées par l’IA » est affichée dans le pied de page conformément au cahier des charges ; pour une livraison finale, elle doit être conservée uniquement si les visuels présentés sont effectivement générés par IA.
